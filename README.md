# App Móvil - Panel de Control Administrativo (Punto Cell)

**Descripción:** 
Aplicación móvil de uso exclusivo para la administración de Punto Cell. Funciona como un panel de control gerencial que permite monitorear y auditar en tiempo real los módulos críticos del negocio: inventario, compras, ventas, reparaciones y la bitácora de movimientos. 
Proyecto desarrollado de manera incremental mediante metodología ABP, adaptando las funciones de gestión de nuestro sistema base.
